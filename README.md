# 🧪 Train EDA Project

## 📌 Overview
Exploratory Data Analysis (EDA) on the Train dataset to identify patterns affecting passenger survival.

## 📂 Dataset
- Source: Kaggle Titanic Challenge
- File: `train.csv`

## 🛠 Tools Used
- Python, Pandas, Matplotlib, Seaborn
- Jupyter Notebook

## 🔍 Key Tasks
- Data cleaning & preprocessing
- Univariate & bivariate analysis
- Visualizations: histograms, boxplots, pairplots, heatmaps
- Observations and summary of findings

## 📄 Deliverables
- Raw Dataset
- `Train_Dataset_Task5.ipynb` – EDA notebook
- PDF report – Summary of insights
- `README.md` – Project overview
